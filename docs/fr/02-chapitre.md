# 2. Registre des opérateurs

Le registre permissionless encadre l’entrée des opérateurs et les paramètres de leurs validateurs. Les contrôles d’éligibilité et les rôles limitent l’ajout de données incohérentes.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
