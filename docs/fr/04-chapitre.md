# 4. Retraits et limites

Les sorties dépendent de la liquidité et des files de retrait. Les hypothèses sur les attestations, les opérateurs et les administrateurs restent essentielles ; ce dépôt est un périmètre d’audit, pas une garantie.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
